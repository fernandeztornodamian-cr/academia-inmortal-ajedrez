# ♟️ Academia Inmortal de Ajedrez

Bienvenido a la **Academia Inmortal de Ajedrez** - Un programa completo para mejorar tu ajedrez.

## 🚀 Características

- 📚 Formación completa en ajedrez
- 👨‍🏫 Entrenadores con experiencia de elite
- 🎯 Plan personalizado según tu nivel
- 📱 Panel de estudiante con acceso privado
- 🔔 Notificaciones automáticas

## 📋 Estructura del Proyecto

```
.
├── index.html          # Landing page
├── css/
│   └── styles.css      # Estilos
├── js/
│   ├── main.js         # Lógica principal
│   └── access.js       # Sistema de acceso
├── admin/
│   └── dashboard.html  # Panel de admin
└── data/
    └── students.json   # Base de datos de estudiantes
```

## 🛠️ Instalación

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. Configura tu número de WhatsApp en `js/main.js`
